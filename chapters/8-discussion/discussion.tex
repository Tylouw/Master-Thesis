\chapter{Discussion}\label{ch:discussion}

Benchmark 1:
Benchmark 1 shows that the selected input representation and model architecture are sufficient to classify unseen insertion attempts from the same experimental distribution with high balanced accuracy. The difference between balanced accuracy and validation loss also shows that the model with the best classification performance is not necessarily the model with the best probability calibration. For the objective of this thesis, the classification decision is more relevant than perfectly calibrated probabilities, which supports the selection of the Big model for the following benchmark evaluations.
